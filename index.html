The idea

pseudocode
while low ≤ high:
    mid = ⌊(low + high) / 2⌋
    if list[mid] == target:
        return mid
    else if list[mid] < target:
        low = mid + 1  // search right
    else:
        high = mid - 1 // search left
return not found
